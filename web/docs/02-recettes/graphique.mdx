# Graphique

Il existe plusieurs librairies permettant d'afficher des graphiques dans une application *Android*.

Dans le cadre de ce cours, nous utiliserons la librairie [MPAndroidChart](https://github.com/PhilJay/MPAndroidChart). Consultez le *README* du dépôt afin de connaître les étapes nécessaires à l'ajout des dépendances permettant d'intégrer cette librairie dans un projet *Android Studio*

Pour découvrir un exemple d'utilisation, référez-vous au projet [ComposeGraphique](https://github.com/departement-info-cem/3N5-Prog3/tree/main/code/ComposeGraphique).

Cet exemple combine des notions abordées précédemment :
- La librairie MPAndroidChart est distribuée via *JitPack*. Il faut donc configurer ce dépôt pour pouvoir l'utiliser dans le projet.
- *MPAndroidChart* repose sur des composants graphiques classiques. Pour les intégrer à une interface *Jetpack Compose*, il faut utiliser *AndroidView*.
