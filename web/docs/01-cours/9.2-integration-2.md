# Intégration 🔨

:::danger

Nous commencerons la séance par un examen théorique sur papier de 20 minutes. 

Le formatif est disponible [ici](https://github.com/departement-info-cem/3M5-Intro-Mobile/blob/main/web/static/A26-formatif-papier-2.md).

Les règles sont les suivantes : 
- droit à une feuille de notes recto-verso manuscrite ou imprimée
- aucun ordinateur ou appareil électronique
- questions de type Compose vers dessin, types et valeurs, et schématiser la navigation entre activités

:::
